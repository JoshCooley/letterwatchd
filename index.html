How to use

  1. Optional: Import your Letterboxd watched.csv or export .zip to hide films you've already logged. Export it at letterboxd.com/user/exportdata.
  2. Swipe the card, use Skip / Watch, or the arrow keys. Right = watched, left = skip. Back (or Backspace) revisits the last film.
  3. Review or remove entries in the Watched and Skipped lists below (collapse either to tidy up). Reset clears everything saved.
  4. Export the CSV, then import it at letterboxd.com/import as watched films.
This product uses the TMDB API but is not endorsed or certified by TMDB.
